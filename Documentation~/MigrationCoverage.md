# Match Rival Visual Ownership

The pre-`0.4.2` package migration copied Cat production prefabs and images into this package. Those duplicate package copies are retired because Cat Merge Cafe production continues to reference local assets under `Assets/_Project/Content/MatchRival`.

Current package visual scope is limited to runtime `Resources` icons, the shared Indicator prefab, and their reachable dependencies. This document does not authorize restoring historical package paths.
